# Columbia Global Morning Intelligence Briefing (exemplar)

A one-page dashboard showing how a single daily briefing across the ten Global Centers can serve several teams. Each development is tagged once (city, category, signal level, teams it matters to) and each team reads its own view: Communications, Operations, Academic Programs, or the full briefing.

Content is adapted from the 1 November 2026 briefing to show the format. It is not a live feed.

Live page: https://anuragmishraapplications-lab.github.io/cg-morning-briefing/
